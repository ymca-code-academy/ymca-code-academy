About the Program

Expanding access to coding education in Paterson

YMCA Code Academy is a volunteer-led youth coding program that provides free classes, online lessons, creative projects, and community opportunities.

Our Story

From a small class to a growing community program

YMCA Code Academy began as a free coding class led by a high school volunteer at the YMCA of Paterson.

The program started with a small group of students learning the basics of computer programming. Students worked with Scratch and Python, completed practice activities, and created games and group projects.

As the classes continued, the program expanded beyond weekly instruction. Funding was raised to improve the YMCA computer lab, new technology was provided for students, and additional opportunities were developed for students to learn and share their work.

The next stage of YMCA Code Academy includes a free online lesson library, a community coding challenge, a student project showcase, and a volunteer program that can help the academy continue in the future.

Our Mission

Helping young students become creators of technology

YMCA Code Academy makes coding education more accessible through free instruction, hands-on projects, and community support.

01

Access

Students can learn coding without paying for private classes or expensive programs.

02

Creativity

Students use code to create games, stories, quizzes, animations, and original projects.

03

Confidence

Students gain confidence by solving problems, presenting their work, and seeing what they are capable of building.

How the Program Has Grown

Building one opportunity at a time

Step 1

Free Coding Classes

Students began learning Scratch and Python through weekly classes at the YMCA of Paterson.

Step 2

Technology Improvements

Nearly $8,000 was raised to help improve the computer lab and provide updated equipment for students and instructors.

Step 3

Student Projects

Students combined their skills to build games, interactive stories, and group coding projects.

Step 4

Free Online Lessons

The YMCA Code Academy website was created so students could continue learning outside of class.

Step 5

Community Code Challenge

Students from across the community will have the opportunity to build and present original programs.

Program Leadership

Created and led by a student volunteer

YMCA Code Academy was created and is led by Ethan Dowling, a high school student volunteer who developed the lessons, taught the classes, organized student projects, supported fundraising efforts, and created this website.

The long-term goal is to build a program that can continue serving students through new volunteers, mentors, lessons, and community events.

YMCA staff provide the space, support, and community partnership that make the program possible.
