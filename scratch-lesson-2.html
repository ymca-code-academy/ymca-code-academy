Key Vocabulary

Words that explain interactive games.

These terms describe how the game responds to the player, remembers information, and controls what happens during each round.

01

Click Event

An event that starts a script when the player clicks a sprite.

02

Variable

A named place where a project stores information that can change.

03

Score

A number that tracks the player's points or progress during a game.

04

Timer

A value that measures how much time has passed since the project began.

05

Random Position

A location chosen automatically from different possible places on the stage.

06

Game Rule

A condition that determines how the player earns points, wins, loses, or finishes.

Concept 01

Click Events

Make the target respond to the player.

The when this sprite clicked event starts a script whenever the player clicks the selected sprite.

Every block connected beneath the event runs in order. The target can earn a point, play a sound, change appearance, and move.

Important

Add the click-event script to the target sprite, not to the stage or another character.

Concept 02

Score and Time

Remember points and control each round.

A score variable stores the number of points earned by the player. Set it to zero at the beginning of every new game.

After the target is clicked, use change score by 1 to increase the score.

Build the Complete Game

Connect the game systems together.

A complete clicker game needs a starting script, a click script, a score, movement, and a clear ending rule.

01

Start the Round

Use the green flag to reset the score and prepare the target.

02

Award Points

Increase the score whenever the correct sprite is clicked.

03

Move the Target

Send the sprite to a new position after every successful click.

04

Add Feedback

Use sounds, size changes, or costumes to show that the click was successful.

05

Increase Difficulty

Make the target smaller, faster, or harder to find as the score increases.

06

End the Game

Stop the round after a time limit or when the player reaches the winning score.

Common Mistakes

Check these problems before testing again.

Scratch games often stop working because one block is attached to the wrong sprite or is placed in the wrong script.

!

The score does not reset

Place set score to 0 under the green-flag event.

!

Clicking does nothing

Make sure the target sprite contains the when this sprite clicked event.

!

The target never moves

Connect go to random position beneath the click event.

!

The game is too easy

Make the target smaller, add a time limit, or move it more frequently.

Extra Challenge

Make the game harder as the score increases.

Reduce the sprite's size, shorten the amount of time available, add a second target, or subtract points when the player clicks the wrong sprite.

Possible Game Rule

Reach 15 points before the timer reaches 30 seconds.
