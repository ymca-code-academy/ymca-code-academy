Key Vocabulary

Words that explain digital storytelling.

These terms describe how scenes, characters, dialogue, timing, and messages work together.

01

Scene

One part of a story that occurs in a particular setting or moment.

02

Dialogue

The words spoken by characters during the story.

03

Backdrop

The background image that establishes where a scene takes place.

04

Broadcast

A message sent through a Scratch project to start another script.

05

Sequence

The order in which instructions and story events occur.

06

Timing

The control of when actions begin and how long they continue.

Concept 01

Scenes and Dialogue

Build the story one scene at a time.

Each scene should have a clear purpose. A scene might introduce a character, present a problem, reveal new information, or resolve the story.

Backdrops establish the setting, while dialogue and movement show what is happening.

Story Planning

Decide what must happen in each scene before connecting the Scratch blocks.

Introducing the Story

Purpose

The wait block keeps dialogue from appearing at the same time.

Concept 02

Broadcasts and Timing

Coordinate characters and scene changes.

A broadcast sends a message to every sprite and the stage. Any script waiting for that message begins immediately.

Broadcasts help separate a large story into organized scenes instead of placing everything underneath one green-flag event.

Clear Message Names

Use names such as start scene 2 or begin ending so each message has an obvious purpose.

Character 1

Sending a Broadcast

say "Follow me!" for 2 seconds

broadcast start scene 2

Result

The message tells the project to begin the next scene.

Stage

Receiving the Broadcast

when I receive start scene 2

switch backdrop to forest

Result

The backdrop changes when Scene 2 begins.

Common Mistakes

Fix these problems before presenting.

Story projects often become confusing when actions run at the wrong time or scripts are attached to the wrong sprite.

!

Characters speak together

Add wait blocks or broadcasts so each line of dialogue occurs in order.

!

A sprite appears in the wrong scene

Use show and hide blocks whenever a new scene begins.

!

The backdrop changes too early

Change it only after the previous scene has finished.

!

A broadcast does nothing

Check that another script begins with the matching when I receive event.
