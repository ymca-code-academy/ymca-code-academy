Key Vocabulary

Words that help programs make decisions.

These terms describe how Python checks information and chooses which code to run.

01

Conditional

Code that makes a decision based on whether a condition is true or false.

02

Condition

A statement or comparison that Python evaluates as true or false.

03

Boolean

A value that can be either True or False.

04

Comparison Operator

A symbol such as ==, >, or < that compares two values.

05

Indentation

The spaces at the beginning of a line that show which code belongs inside a conditional.

06

Branch

One possible path that a program can follow after making a decision.

Concept 01

If Statements

Run code only when something is true.

An if statement checks a condition. When the condition is true, Python runs the indented code beneath it.

When the condition is false, Python skips the indented code and continues with the program.

Structure

Begin with if, write the condition, add a colon, and indent the code that should run.

Example 1

Checking a Score

score = 10

if score >= 10 :

    print("You reached the goal!")

Output

You reached the goal!

Example 2

Checking a Password

password = "python"

if password == "python" :

    print("Access granted")

Output

Access granted

Concept 02

Elif and Else

Give your program more than one path.

Use elif when you want Python to check another condition after the first condition is false.

Use else as the final path. The else block runs when none of the earlier conditions are true.

Order Matters

Python checks the conditions from top to bottom and runs the first matching branch.

Example 3

Three Possible Results

score = 8

if score >= 10 :

    print("Excellent score!")

elif score >= 5 :

    print("Good job!")

else :

    print("Keep practicing!")

Output

Good job!
Decision Order
if → elif → else

Python follows the first branch whose condition is true. If no condition is true, it follows the else branch.
