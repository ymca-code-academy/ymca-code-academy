Rhino Survival

Your journey is about to begin.

You are a rhino living in the rainforest. Poachers are nearby, and you must make careful choices to reach safety.

This browser version preserves the students' original story and decision-based game while making it playable directly on the website.

Project Goal

A game designed to raise awareness.

The students wanted to create more than an entertaining story. They focused their project on rhinos that are threatened by poaching for their horns.

By placing the player in the role of the rhino, the game encourages players to think about the danger from the animal's point of view.

01

Teach players about an important conservation problem.

02

Use an interactive story to make the issue easier to understand.

03

Show that computer programming can be used to communicate a meaningful message.

The Issue Behind the Game

Why rhino conservation matters.

Rhino Survival uses storytelling and coding to introduce players to the continuing threat of illegal rhino poaching.

26,700

Estimated Rhinos Worldwide

The International Rhino Foundation estimates that approximately 26,700 rhinos remain across all five surviving rhino species.

352

Poached in South Africa in 2025

South Africa reported 352 rhinos poached during 2025. This was lower than the 420 reported in 2024, but it remains a serious conservation problem.

Keratin

What Rhino Horn Is Made Of

Rhino horn is primarily made of keratin, the same type of protein found in human hair and fingernails.

Student Inspiration

Turning concern into a coding project.

The students learned that rhinos continue to be targeted for their horns. They felt that this was an important environmental issue and wanted to raise awareness through a fun, choice-based story.

Instead of only presenting facts, they created a game in which the player becomes the rhino and must escape danger. The project shows how code can combine education, creativity, and advocacy.

!

Important Fact

Rhino horn is not a proven medicine.

Claims about medicinal benefits have helped create demand for rhino horn, but scientific evidence does not support those claims. Continued demand contributes to illegal wildlife trafficking and poaching.

Original Project Code

See how Rhino Survival was programmed.

The code below shows the Python structure behind the original class project, including random outcomes, player input, conditionals, lists, and replay logic.

rhino_survival.py

import random

        restart = "yes"

        while restart == "yes":
            print(
                "Welcome to Rhino Survival! "
                "You are a rhino in the rainforest."
            )

            poachers = [
                "Sniper",
                "Bombers",
                "K. Danny",
                "John Cena"
            ]

            random_number = random.randint(1, 2)

            choice_1 = input(
                "As a rhino in the rainforest, you must "
                "survive the poachers. Choose to RUN or HIDE: "
            ).lower()

            survived_first_choice = False

            if choice_1 == "run":
                if random_number == 1:
                    poacher_1 = random.choice(poachers)
                    print(
                        poacher_1
                        + " catches you. You lost..."
                    )
                else:
                    print(
                        "You saw Banana Bo! You survive!"
                    )
                    survived_first_choice = True

            elif choice_1 == "hide":
                if random_number == 1:
                    poacher_2 = random.choice(poachers)
                    print(
                        poacher_2
                        + " sees and catches you. You lost..."
                    )
                else:
                    print(
                        "You saw Banana Bo! You survive!"
                    )
                    survived_first_choice = True

            else:
                print(
                    "That was not a choice. "
                    "Please type RUN or HIDE."
                )

            if survived_first_choice:
                choice_2 = input(
                    "Banana Bo asks if you are going "
                    "to the RIVER or going to HIDE: "
                ).lower()

                if choice_2 == "river":
                    print(
                        "The rhino goes to the river with "
                        "Banana Bo and is safe from the "
                        "poachers. YOU SURVIVED!"
                    )
                else:
                    poacher_3 = random.choice(poachers)

                    print(
                        poacher_3
                        + " finds you and sends you to the zoo."
                    )

            restart = input(
                "Do you want to replay? YES or NO: "
            ).lower()

        print("Thanks for playing Rhino Survival!")

What is happening in the program?

Import Random

The random module allows the program to create different outcomes each time.

02

Store the Poachers

A Python list stores several possible characters that the program can select.

03

Ask for Decisions

The input function asks whether the player wants to run, hide, or travel to the river.

04

Check the Choices

If, elif, and else statements decide what happens after each answer.

05

Replay the Game

A while loop lets the player begin a new adventure after the game ends.

i

The formatting and game flow have been cleaned up for the website so that the code is easier to read and the second decision only appears when the rhino reaches that point in the story. The project concept, choices, characters, and conservation message come from the original student-created game.
