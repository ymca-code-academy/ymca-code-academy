Key Vocabulary

Words that explain reusable code.

These terms describe how functions are created, run, and given information.

01

Function

A named section of code designed to perform a specific task.

02

Define

To create a function using the def keyword.

03

Call

To run a function by writing its name and parentheses.

04

Parameter

A variable listed in a function definition that receives information.

05

Argument

The actual value passed into a function when it is called.

06

Return Value

Information that a function sends back to the part of the program that called it.

Concept 01

Creating Functions

Give a reusable task a name.

A function begins with the def keyword followed by the function name and parentheses.

The indented code beneath the definition belongs to the function, but it does not run until the function is called.

Structure

Write def, the function name, parentheses, a colon, and an indented block of code.

Example 1

Defining a Function

def show_message ():

    print("Keep learning Python!")

Important

Nothing displays until the function is called.

Example 2

Calling a Function

show_message ()

Output

Keep learning Python!

Function Structure

Every part has a purpose.

Functions need a keyword, name, parentheses, colon, indentation, and a function call.

def

Definition Keyword

def greet(): Tells Python that a function is being created.
()

Parentheses

greet() Appear in both the definition and call.
:

Colon

def greet(): Ends the first line of the definition.
!

Indentation

    print("Hi") Shows which code belongs to the function.

Concept 02

Parameters and Arguments

Give a function information to use.

A parameter is written inside the function definition. It acts like a variable inside the function.

An argument is the real value supplied when the function is called.

Example

In greet("Maya"), the string "Maya" is the argument.

Example 3

Using One Parameter

def greet (name):

    print("Hello,", name )

greet ("Maya")

greet ("Luis")

Output

Hello, Maya
Hello, Luis

Example 4

Using Two Parameters

def show_score (name, score ):

    print(name, "scored" , score )

Function Call

show_score("Jordan", 10)

Common Function Mistakes

Check the name, colon, and indentation.

Small syntax mistakes can prevent a function from being created or called correctly.

✓

Correct Definition

def start_game(): Includes def, parentheses, and a colon.
✓

Correct Call

start_game() Uses the exact function name.
×

Missing Parentheses

def start_game: Add parentheses before the colon.
×

Function Never Called

def start_game(): Defining a function does not run it.
