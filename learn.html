Not sure which one to choose?

Begin with Scratch if this is your first coding experience or you would rather build programs with visual blocks. Choose Python if you are comfortable typing and are ready to write commands. You can return and complete the other path later.

↗

The lessons and coding editors work together.

Keep the YMCA Code Academy lesson open in one browser tab and the Scratch or Python editor open in another. Read each explanation on this website, then build and test the code inside the editor.

Scratch and Replit may ask students to create a free account to save projects. Students should follow their parent, guardian, teacher, or program instructor's rules for creating online accounts.
