Lesson Overview

What will you learn?

By the end of this lesson, you will be able to select a sprite, use the Scratch stage, connect blocks, start code with an event, and build a short animation.

01

Understand the Workspace

Identify the stage, sprites, block menu, coding area, and green flag.

02

Connect Blocks

Drag blocks into the coding area and connect them in the order they should run.

03

Build an Animation

Combine motion, looks, events, and costumes to create an animated scene.

!

Before You Begin

You do not need any coding experience.

Scratch uses colorful blocks instead of typed commands. Experiment with the blocks, test your project often, and do not worry about making mistakes.

Key Vocabulary

Words every new Scratch creator should know.

These terms explain the characters, workspace, instructions, and events used in a Scratch project.

01

Sprite

A character or object that can move, speak, change appearance, and follow instructions.

02

Stage

The area where the Scratch project and its animations are displayed.

03

Block

A colorful instruction that tells a sprite what to do.

04

Script

A connected group of blocks that works together as a program.

05

Event

An action that starts a script, such as clicking the green flag.

06

Costume

One appearance or pose that belongs to a sprite.

Concept 01

Sprites and the Stage

Choose what appears in your animation.

A sprite is a character or object that follows your blocks. Every sprite can have its own code, position, costumes, and sounds.

The stage is the background area where the animation happens. You can change its backdrop to create a new setting.

Important

Always check which sprite is selected before adding blocks. The blocks are added only to the selected sprite.

Block Categories

Choose blocks based on the action you need.

Scratch organizes blocks into categories. Each category uses a different color and controls a different part of the project.

M

Motion

move 10 steps Moves, turns, glides, or changes a sprite's position.
L

Looks

say "Hello!" Changes appearance, displays speech, or switches costumes.
E

Events

when green flag clicked Starts code when something happens.
C

Control

wait 1 second Controls timing, repetition, and the order of actions.

Concept 02

Blocks and Events

Connect instructions in the order they should run.

Scratch reads a connected script from top to bottom. The first block is often an event that tells Scratch when to start.

Blocks underneath the event run one at a time in the order they are connected.

Start Here

Use the “when green flag clicked” event at the top of a basic animation script.

Example 1

A Simple Movement Script

when green flag clicked

go to x: -150 y: 0

glide 2 seconds to x: 150 y: 0

Result

The sprite glides from left to right.

Example 2

Movement and Speech

when green flag clicked

say "Watch me move!" for 2 seconds

move 100 steps

next costume

Result

The sprite speaks, moves, and changes pose.

Practice

Costumes and Timing

Make movement feel animated.

Switching costumes and adding short waits can make a sprite appear to walk, dance, or change expressions.

1

Change Costume

next costume Switches the sprite to its next appearance.
2

Add a Wait

wait 0.2 seconds Creates a small pause between actions.
3

Move Again

move 10 steps Changes the sprite's position.
!

Test the Speed

wait 2 seconds A long wait may make the animation feel slow.

Common Scratch Mistakes

Check the sprite, event, and block connection.

Scratch blocks prevent many typing errors, but projects can still behave differently than expected.

✓

Event at the Top

when green flag clicked Gives the script a clear starting event.
✓

Blocks Connected

event → motion → looks Connected blocks run as one script.
×

Wrong Sprite Selected

Sprite 2 selected The code may be added to the wrong character.
×

Loose Block

move 10 steps A loose block does not run with the connected script.
