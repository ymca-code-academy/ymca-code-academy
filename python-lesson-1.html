Concept 01

Print Statements

Make Python display a message.

The print() command tells Python to display information on the screen.

When you want Python to display text, place the text inside quotation marks.

Remember

Text needs quotation marks. The quotation marks tell Python that the information is a string.

Example 1

Basic Print Statement

print ("Hello, world!")

Output

Hello, world!

Example 2

Printing a Number

print (25)

Output

25

Concept 02

Variables

Give information a name.

A variable stores information so that your program can use it later.

Imagine a variable as a labeled container. The variable name is the label, and the value is what you place inside.

variable_name = value
Important

A single equals sign stores a value inside a variable.

student_name
"Maya"

The variable student_name stores the value "Maya".

Example 3

Creating and Printing a Variable

student_name = "Maya"

print (student_name)

Output

Maya

Variable Rules

Choose clear variable names.

Good variable names make your program easier to understand and fix.

✓

Good Variable Name

favorite_color Clear and descriptive
✓

Good Variable Name

player_score Uses an underscore between words
×

Incorrect Variable Name

favorite color Variable names cannot contain spaces
×

Incorrect Variable Name

1st_name Variable names cannot begin with a number
