Key Vocabulary

Words that explain repeated code.

These terms describe how loops repeat actions, count repetitions, and decide when to stop.

01

Loop

A section of code that repeats an action or group of actions.

02

Iteration

One complete repetition of a loop.

03

For Loop

A loop often used when the number of repetitions is already known.

04

While Loop

A loop that repeats while a condition remains true.

05

Range

The Python range() function produces a sequence of numbers for a loop.

06

Infinite Loop

A loop that never stops because its condition never becomes false.

Concept 01

For Loops

Repeat code a specific number of times.

A for loop is useful when you know how many times an action should repeat.

The range() function tells Python how many iterations to complete.

Structure

Write for, create a loop variable, use in range(), add a colon, and indent the repeated code.

Example 1

Repeating a Message

for number in range (3):

    print("Python is powerful!")

Output

Python is powerful!
Python is powerful!
Python is powerful!

Example 2

Displaying Loop Numbers

for number in range (5):

    print(number)

Output

0   1   2   3   4

Understanding Range

Control where the counting starts and stops.

The range function can use one, two, or three numbers to control a loop.

1

One Number

range(5) Produces 0, 1, 2, 3, and 4.
2

Start and Stop

range(1, 6) Produces 1, 2, 3, 4, and 5.
3

Start, Stop, and Step

range(0, 10, 2) Produces 0, 2, 4, 6, and 8.
!

Important

range(5) The ending number is not included.

Concept 02

While Loops

Repeat code while a condition is true.

A while loop checks a condition before each repetition.

The loop continues while the condition is true and stops when the condition becomes false.

Important

Change the variable inside the loop so the condition can eventually become false.

Example 3

Counting Up

count = 1

while count <= 3 :

    print(count)

    count = count + 1

Output

1   2   3
Loop Condition
count <= 3

After each repetition, count increases. The loop stops when count becomes 4.

Common Loop Mistakes

Check the structure before running the code.

Most loop errors come from missing colons, incorrect indentation, or conditions that never become false.

✓

Correct

for number in range(5): The loop ends with a colon.
✓

Correct

    print(number) The repeated line is indented.
×

Incorrect

for number range(5): The keyword in is missing.
∞

Infinite Loop

while count < 5: The value of count never changes.
