Key Vocabulary

Words that make programs interactive.

These terms explain how a Python program can ask questions, collect information, and respond to a user.

01

Input

Information entered into a program by the user.

02

User

The person who is currently interacting with the program.

03

Input Function

The Python input() function asks a question and waits for an answer.

04

Prompt

The question or message displayed inside the input function.

05

Response

The answer that the user types into the program.

06

Interactive Program

A program that responds differently based on information supplied by the user.

Concept 01

The Input Function

Ask the user a question.

The input() function displays a question and pauses the program until the user types an answer.

The question inside the parentheses is called the prompt. It should clearly tell the user what to enter.

Remember

The prompt is text, so it must be placed inside quotation marks.

Example 1

Asking a Question

input ("What is your name? ")

Program

What is your name? Maya

Example 2

Asking About a Hobby

input ("What is your favorite hobby? ")

Concept 02

Storing Answers

Save the user's response.

An input statement becomes much more useful when the user's answer is stored inside a variable.

The variable goes before the equals sign, and the input function goes after it.

variable_name = input("Question")
Important

Without a variable, Python can ask the question, but your program will not have a name for the answer that it receives.

favorite_food
"pizza"

The user's answer is stored inside the variable favorite_food.

Example 3

Saving and Using an Answer

favorite_food = input ("What is your favorite food? ")

print ("You like", favorite_food )

Program Conversation

Common Mistakes

Check the structure of your input statement.

Small syntax mistakes can prevent Python from asking the question correctly.

✓

Correct

name = input("What is your name? ") The prompt has quotes and parentheses.
✓

Correct

print("Hello,", name) The stored answer is used through its variable.
×

Incorrect

name = input(What is your name?) The prompt is missing quotation marks.
×

Incorrect

name input("What is your name?") The equals sign is missing.
