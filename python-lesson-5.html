Key Vocabulary

Words that explain Python collections.

These terms describe how lists store, organize, and provide access to multiple values.

01

List

An ordered collection that stores multiple values inside one variable.

02

Item

One individual value stored inside a list.

03

Index

The numbered position of an item inside a list.

04

Square Brackets

The [ ] symbols used to create a list and access its items.

05

Append

To add a new item to the end of an existing list.

06

Length

The total number of items stored inside a list.

Concept 01

Creating Lists

Store several values inside one variable.

A normal variable stores one value. A list lets one variable store an entire collection of related values.

Place the items inside square brackets and separate each item with a comma.

Structure

Write the variable name, an equals sign, and the list items inside square brackets.

Example 1

A List of Strings

colors = ["red", "blue" , "green" ]

Stored Values

red, blue, green

Example 2

A List of Numbers

scores = [8, 10 , 7 , 9 ]

Number of Items

4 scores

Practice

Index Positions

Python begins counting at zero.

Every list item has a numbered position. Use that index number inside square brackets to access one item.

0

First Item

colors[0] Accesses "red".
1

Second Item

colors[1] Accesses "blue".
2

Third Item

colors[2] Accesses "green".
!

Common Mistake

colors[3] This causes an error because the list has no fourth item.

Concept 02

Using and Updating Lists

Access, add, and process list items.

You can access one item with its index, add a new item with append(), or use a loop to process every item.

Lists work especially well with for loops because Python can visit each stored value in order.

Remember

The name after for represents one item during each loop iteration.

Example 3

Accessing an Item

games = ["Maze", "Trivia" , "Adventure" ]

print (games[1])

Output

Trivia

Example 4

Adding an Item

games .append("Racing")

print (games)

Updated List

Maze, Trivia, Adventure, Racing

Lists and Loops

Perform an action for every item.

A for loop can move through the list in order and temporarily store each item inside a loop variable.

Example 5

Looping Through Student Names

students = ["Maya", "Jordan" , "Luis" ]

for student in students :

    print("Welcome,", student )

Output

Welcome, Maya
Welcome, Jordan
Welcome, Luis

Common List Mistakes

Check the brackets, commas, and indexes.

Most beginner list errors come from missing punctuation or requesting an index that does not exist.

✓

Correct Brackets

pets = ["cat", "dog"] List items are inside square brackets.
✓

Correct Commas

scores = [5, 8, 10] Each item is separated by a comma.
×

Missing Comma

pets = ["cat" "dog"] Add a comma between the strings.
×

Invalid Index

pets[2] A two-item list only uses indexes 0 and 1.
